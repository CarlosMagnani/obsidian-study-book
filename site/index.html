How it works

Three steps, one command.

  1. 01

    Download

    The plugin runs yt-dlp on your machine and saves the audio inside a hidden folder of your vault. No file leaves your computer before you ask it to.

  2. 02

    Transcribe

    The audio goes to the transcription provider you configured. OpenAI and Gemini both return text with timestamps, so the note can point back to the exact moment.

  3. 03

    Write the note

    The transcript goes to the analysis model, which returns a topic, a summary, key points and moments. The plugin writes it as Markdown in the folder you chose.

Bring your own key

Your provider, your bill, your rules.

The plugin has no account, no server and no key of its own. The key is stored in this vault only, and every request goes straight from your machine to the provider you chose.

OpenAI

Transcription and analysis, with strict JSON schemas so the note always has the same shape.

default

Anthropic

Compatible gateways

Every provider accepts a custom base URL, so a proxy or a gateway that speaks the same API works without a code change.

The note

Plain Markdown, frontmatter included.

The output is a file in your vault, not a database. Dataview, Canvas, Templates, Sync and every other plugin keep working, because it is only Markdown.

Privacy

What leaves your machine, and what does not.

  • No telemetry

    No analytics, no crash reports, no background calls of any kind.

  • The key stays here

    It is stored in .obsidian/plugins/study-book/data.json and only travels inside the request to the provider you selected.

  • The audio is temporary

    It is deleted right after the run, unless you turn on Keep the audio file.

  • The transcript is sent

    The analysis needs the text, so the transcript goes to the analysis provider. That is the only other copy that exists.

FAQ

Before you install.

Do I need an API key?

Yes, at least one. The plugin never ships a key of its own. OpenAI is the default, and Anthropic and Gemini are one dropdown away.

Does it work without a GPU?

Yes. Every model runs on the provider's servers. The only local work is the download, which is light.

Why does it need yt-dlp?

yt-dlp is the tool that knows how to fetch the audio of a video. It is free and open source. If it is already on your PATH the plugin finds it; otherwise you point the settings at the binary.

Can I use a transcript I already have?

Yes. The command Analyze a transcript that you already have skips the download and the transcription entirely.

Does it work on mobile?

No, and the plugin says so in the manifest. Downloading a video needs a process on your operating system, which mobile does not allow.

Can I change the shape of the note?

Yes. The folder, the language of the notes and the list of allowed topics are settings. The Markdown template itself lives in src/pipeline/note.ts, and it is a plain function.
